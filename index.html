Threat Intelligence

APT攻击案例信息抽取系统

把APT报告中的组织、技术、IOC、工具和攻击步骤抽取出来，写入Neo4j并形成知识图谱、攻击链对比和数据质量诊断。

React · Python · Neo4j · ATT&CK · Knowledge Graph
Encrypted Traffic

基于元学习的加密流量分析系统

串联pcap检测、元学习模型推理、告警处置、MITRE归类、溯源任务和态势大屏，形成加密流量分析闭环。

Vue · ECharts · Node.js · MySQL · Meta Learning
Workflow System

留学申请与审核系统

围绕申请提交、国内审核、学校审核、候补调剂、名额占位和审计日志构建业务管理系统。

Spring Boot · Vue · MySQL · JWT · MyBatis-Plus
Desktop Security

Smart File Manager

把桌面文件管理、AI摘要、语义检索、隐写处理、风险审计和实时监控组合成智能安全文件管理系统。

Tauri · Rust · Next.js · FastAPI · pgvector
